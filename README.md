### 🚀 O que eu construo

**Base em comum:** Python no backend, processamento automatizado de dados (Pandas), integrações de hardware/software, e persistência estruturada.

| Projeto | O que é |
| :--- | :--- |
| **[Logística Família Feliz](https://github.com/Ohlipeh/app-logistica-familia-feliz)** | Aplicação para otimizar a gestão de frota, coletas e deslocamentos sociais para a ONG Família Feliz (Blumenau). Sincronização em tempo real via **Google Sheets API**. Interface em CustomTkinter/Flask rodando em PythonAnywhere. |
| **NYX Assistant** | Assistente de IA automatizado para WhatsApp. Arquitetura conteinerizada em **Docker** com integração de mensageria via **Evolution API** e Flask. |
| **[TravelWorldMarka](https://github.com/Ohlipeh/TravelWorldMarka)** | Sistema de integração de afiliação voltado para Mercado Livre e Amazon. Construído com Python e banco de dados gerenciado em nuvem via **Supabase**. |
| **[CSVCleaner](https://github.com/Ohlipeh/CSVCleaner)** | Automação scriptada em **Pandas** para higienização, formatação corporativa e deduplicação de grandes volumes de dados brutos empresariais, exportando para Excel. |
| **Monitor JARVAN (IoT)** | Sistema interativo de display físico escrito em **MicroPython**. Roda em microcontrolador ESP32 com display OLED SSD1306 e hardware de áudio (buzzer/módulo I2S). |
| **[Validador de Documentos](https://github.com/Ohlipeh/Validador_de_documentos)** | Módulo de backend independente focado em regras de negócio para garantir segurança e sanitização estrita em identificadores fiscais/civis (CNPJ, NFe, RG). |
